# 목회자 실전 바이브 코딩 동반 예제

책 『클로드 코드 창시자의 방식으로 배우는 목회자 실전 바이브 코딩』(백형진 지음, 목회AI연구소 제공)에 나오는 예제 모음입니다.

## 받는 방법
1. 이 페이지 위쪽 파일 목록에서 vibe-coding-pastor-examples.zip 을 누릅니다.
2. 오른쪽 위의 "Download raw file" 단추(아래 화살표 모양)를 눌러 내려받습니다.
3. 문서 폴더에 압축을 풉니다. 풀린 폴더 안에 ch00-hello-harness 같은 예제 폴더가 있습니다.

## 이 예제로 할 수 있는 것
| 폴더 | 장 | 내용 |
| --- | --- | --- |
| ch00-hello-harness | Ch 0 | 장절 존재 검사 최소 예제 |
| ch05-locked-harness | Ch 4~5 | 봉인, 기준서 점검기, 3-Agent, 신학 리뷰 서명 |
| app1-scripture-check | Ch 6 | 앱 1 성경 장절 검증 |
| app2-bulletin | Ch 7 | 앱 2 모바일 주보와 게시 전 검사기 |
| app3-visit-anon | Ch 8 | 앱 3 심방 메모 익명화 |
| app4-quiz | Ch 9 | 앱 4 나눔 질문과 성경 퀴즈 |
| app5-event-settle | Ch 10 | 앱 5 행사 등록과 회비 정산 |
| ch11-publish-check | Ch 11 | 교회용 공개 전 점검기 |
| ch12-rule-journal | Ch 12 | 규칙 일지 도구 |
| common | Ch 6~11 | 공통 모듈 |

각 폴더에서 python scripts/verify.py 를 실행하면 책에 나온 검증이 돌아갑니다.
